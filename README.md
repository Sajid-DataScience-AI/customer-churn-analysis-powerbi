## 🚀 Project Overview
This project presents a complete **end-to-end Customer Churn Analysis and Prediction system** using SQL, Power BI, and Machine Learning.

The objective is to analyze customer behavior, identify key churn drivers, and predict customers who are likely to leave, enabling businesses to take proactive actions.
This project helps businesses reduce customer churn using data-driven insights and predictive analytics

---

## 🎯 Business Problem
Customer churn directly impacts revenue and growth. This project answers:

- Why are customers leaving?
- Which customers are at high risk?
- How can churn be reduced?

---

## 🛠️ Tools & Technologies
- **SQL Server** → ETL (Data Cleaning & Transformation)  
- **Power BI** → Dashboard & Visualization  
- **Python (Jupyter Notebook)** → Machine Learning  
- **Random Forest** → Churn Prediction  

---

## 🔄 Workflow

### 1️⃣ ETL (SQL)
- Loaded raw data into staging table  
- Cleaned data (handled null values)  
- Created production tables and views  

### 2️⃣ Power BI Dashboard
- Data transformation using Power Query  
- DAX measures for KPIs (Churn Rate, Total Customers)  
- Built interactive dashboards  

### 3️⃣ Machine Learning
- Applied Random Forest model  
- Train-test split (80/20)  
- Achieved **84% accuracy**  

### 4️⃣ Prediction
- Identified **378 high-risk customers**  
- Visualized prediction results in Power BI

## 📈 Key Insights
- Competitor offers and devices are major churn drivers  
- Customers without additional services show **>60% churn risk**  
- Older age groups have higher churn probability  
- Low engagement customers are more likely to churn  

---

## 🤖 Machine Learning Results
- Model: Random Forest  
- Accuracy: **84%**  
- Predicted: **378 churn-risk customers**
